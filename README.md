很多人第一次接触搬瓦工（BandwagonHost）时都会卡在同一个地方：套餐太多，线路名称看不懂，优惠码到底还能不能用也没人给个准话。这篇教程把从选套餐、填优惠码到支付宝付款的完整流程拆开讲清楚，顺带说清楚哪些套餐值得买、哪些线路适合谁。

## 一、先搞清楚搬瓦工到底卖什么

搬瓦工是一家老牌海外 VPS 服务商，主打 KVM 虚拟化的自管理 VPS。简单说，你花钱租一台远程服务器，拿到 root 权限，自己装系统、跑程序、建站、搭代理都行。它不提供 cPanel 面板，也没有"一键建站"那种托管服务，所有东西都要自己动手——这也是它能把价格压下来的原因。

搬瓦工最大的卖点是**针对中国大陆优化过的线路**。普通美国 VPS 到国内延迟动辄 200ms 以上，晚高峰还丢包；搬瓦工的 CN2 GIA 系列走电信 CN2 GIA 专线，三网回程都优化过，延迟和稳定性明显好于普通线路。这也是为什么它在国内用户里口碑一直不错。

如果你只是想找一台便宜机器跑个脚本、做个备份，普通 KVM 套餐就够了；如果你要建站、科学上网或者对延迟敏感，那就得看 CN2 GIA 系列。

## 三、这些套餐到底怎么选

看完表格你可能更懵了——这么多类别，到底哪个适合自己？这里按使用场景拆开说。

### 1. 纯粹想省钱、对延迟不敏感

**选 KVM 标准版年付 $49.99 那档**（2核/1GB/20GB/1TB）。这是搬瓦工最便宜的入门套餐，走的是美国普通线路（DC2 QNET、DC4 MCOM、DC8 ZNET、Fremont 等），晚高峰到国内可能会有点抖，但拿来跑个轻量脚本、做个临时测试环境、挂个小网站完全够用。一年不到 50 美元，折合人民币 350 块左右，性价比很高。

如果你需要更多内存和流量，往上一档是 3核/2GB/40GB/2TB，年付 $99.99，配置翻倍但价格也翻倍，看需求决定。

### 2. 建站、科学上网、对稳定性有要求

**选 CN2 GIA-E 季付 $49.99 那档**（2核/1GB/20GB/1TB，2.5Gbps 带宽）。这是搬瓦工目前性价比最高的优化线路套餐，三网回程走 CN2 GIA，可选 DC6、DC9、日本软银（JPOS_1）、EUNL_9 等多个机房。季付 49.99 美元，年付 169.99 美元，在价格、性能、线路和可折腾空间之间算是一个比较均衡的方案。

这类套餐的典型适用人群：想长期用一台 VPS，放个小站、跑个代理服务，或者对国内访问速度有要求但又不想花太多钱。如果你是第一次买搬瓦工又想体验优化线路，从这档入手不会错。

> 如果你预算更紧，可以关注搬瓦工偶尔补货的限量版套餐（比如 The DC9 Plan、MINICHICKEN 等），价格更低但库存不稳定，需要蹲守。

### 3. 对延迟极致敏感、预算充足

**选香港 CN2 GIA 或东京 CN2 GIA**。香港机房直连大陆，延迟通常在 30-50ms，东京也在 50-70ms 区间，明显比美国机房快。但价格也贵得多——香港最低 $89.99/月、$899.99/年，东京最低 $89.99/月、$899.99/年。

适合的人群：做跨境电商、对国内用户访问速度有极致要求、或者就是想要最低延迟。新加坡 CN2 GIA（$49.99/月起）和大阪 CN2 GIA（$49.99/月起）是相对便宜一点的亚洲选项，延迟比美国好但比香港/东京略高。

### 4. 商用、对 SLA 有硬性要求

**选 SLA 商用版**（洛杉矶 DC5）。这档提供 99.99% 服务等级协议（SLA），用 AMD 专用 CPU、NVMe 硬盘、双冗余网络，还支持每两周免费换一次 IP。起步 $65.89/季、$239.99/年，比普通 CN2 GIA-E 贵，但硬件和网络冗余规格更高，适合放正式业务、不能接受宕机的场景。

### 5. 想要中东节点

**选迪拜 ECOMMERCE**。起步 $19.99/月、$169.99/年，机房在迪拜（AEDXB_1），买完之后还可以免费迁入 DC6 CN2 GIA-E、DC9 CN2 GIA、日本软银等线路，相当于花迪拜的钱用上优化线路。适合有中东业务需求或者想要一个冷门地区 IP 的用户。

## 四、搬瓦工购买完整流程

选定套餐后，实际购买流程其实不复杂，但有几个细节容易踩坑，这里一步步说。

### 第一步：进入套餐购买页

直接点上面表格里对应套餐的"立即购买"链接，会跳转到搬瓦工官网的订单页面。如果你是第一次访问，建议用 Chrome 浏览器并开启翻译，搬瓦工官网默认是英文界面。

> 搬瓦工官网主域名 `bandwagonhost.com` 在国内部分网络下可能打不开，镜像站 `bwh81.net` 通常可以正常访问，两个域名背后是同一套系统，账号和套餐通用。

### 第二步：选择计费周期和机房

进入订单页后，首先要选 **Billing Cycle**（计费周期）。搬瓦工一般提供月付、季付、半年付、年付几种选项，时间越长单价越低。比如 CN2 GIA-E 入门档季付 $49.99，年付 $169.99，折算下来年付每月只要 $14.17，比季付便宜不少。如果你确定长期用，直接选年付最划算。

然后选 **Location**（机房位置）。不是所有套餐都能选所有机房——CN2 GIA-E 系列可以在 DC6、DC9、日本软银、EUNL_9、DC3 CN2、DC8 ZNET 等之间切换；KVM 标准版可选 DC2、DC4、DC8、Fremont、USNJ、USNY 等；香港/东京/新加坡/大阪套餐则是固定机房。

> 机房选择会影响国内访问速度。一般来说，CN2 GIA 线路里 DC6 和 DC9 是最热门的，日本软银（JPOS_1）对联通用户友好，EUNL_9 是欧洲节点。选完之后可以后续在 KiwiVM 面板里免费迁移机房，不用一次定死。

### 第三步：填写优惠码

这是省钱的关键一步。在订单页的 **Promotional Code** 输入框里填入优惠码，点 **Validate Code** 验证，验证通过后价格会自动减掉对应折扣。

目前社区里流传最广、折扣力度也还算可用的优惠码是 **`BWHCGLUKKB`**，提供 **6.77% 循环折扣**，新购和续费都能用，相当于终身打 93 折左右。虽然折扣不算大，但搬瓦工的优惠码是循环生效的——续费时也会自动应用同一个码，长期用下来能省不少。

> 优惠码状态会变化。2026 年 2 月搬瓦工短暂放出过 `NODESEEK2026`（6.77% 循环折扣），但只持续了两天就失效了。2025 年双十一期间有 `ILOVEBANDWAGON`（11% 循环折扣），也是限时码。如果你看到某个码验证不通过，说明已过期，换一个或者直接原价购买即可。每年双十一和黑五搬瓦工通常会放出力度更大的限时码，可以蹲一下。

### 第四步：注册账号或登录

填完优惠码后点 **Continue** 进入下一步。如果你已有搬瓦工账号，直接登录；没有的话需要注册一个新账号。

注册时填的信息要点：

- **邮箱**：用真实邮箱，订单确认、续费提醒、服务通知都发到这里
- **密码**：设强密码，搬瓦工账号被盗的案例不少
- **个人信息**：姓名、地址等尽量填真实信息，避免被风控
- **国家**：如实选择，不要乱填

注册完成后会自动跳回订单页，继续付款流程。

### 第五步：选择支付方式付款

搬瓦工支持几种支付方式，对国内用户最友好的是 **支付宝（Alipay）**，此外还支持 PayPal、信用卡、银联等。选 Alipay 后点 **Complete Order**，会跳转到支付宝支付页面，扫码或跳转支付宝 App 完成付款即可。

> 付款时金额是美元，支付宝会按实时汇率折算成人民币扣款。偶尔会遇到 `SECONDARY_MERCHANT_STATUS_ERROR` 报错，通常是支付宝侧的临时问题，刷新重试或换 PayPal 一般能解决。

### 第六步：查收 VPS 信息

付款成功后，搬瓦工会往注册邮箱发一封包含 VPS 信息的邮件，里面有 IP 地址、root 密码、KiwiVM 面板地址等。同时登录搬瓦工后台 → **Services** → **My Services** 也能看到所有已购 VPS。

### Q1：搬瓦工支持退款吗？

搬瓦工提供 **30 天退款保证**，但仅限新购且未违反服务条款的订单。如果你因为滥用被封号，不在退款范围内。退款一般原路返回，支付宝付款的退回到支付宝。

### Q2：续费会涨价吗？

不会。搬瓦工续费价格和首购价格一致，而且如果你首购时用了优惠码，续费时同一个码会自动应用，继续享受折扣。这也是为什么建议首购时就填上优惠码。

### Q3：流量用超了怎么办？

流量超了 VPS 会被暂停，等到下个计费周期开始才恢复。搬瓦工不支持超额按量计费，所以流量套餐要选够。如果你经常超，要么升级到更高流量套餐，要么考虑搬瓦工偶尔推出的超大流量限量版套餐。

### Q4：能不能换 IP？

普通套餐换 IP 需要付费（约 $8.79/次）。SLA 商用版套餐支持**每两周免费换一次 IP**，这是它和普通 CN2 GIA-E 的一个重要区别。如果你的业务对 IP 信誉敏感（比如建站、发邮件），SLA 版本的免费换 IP 福利很实用。

### Q5：搬瓦工被封了怎么办？

如果是因为滥用（跑违规流量、被投诉等），搬瓦工会直接暂停服务且不退款。如果是 IP 被墙（国内访问不通），可以在 KiwiVM 面板里迁移到其他机房试试，或者付费换 IP。搬瓦工对滥用比较严格，使用时注意遵守服务条款。

### Q6：新手第一次买，选哪个最稳妥？

如果预算有限、想先体验一下，选 **KVM 标准版年付 $49.99**，便宜够用。如果对国内访问速度有要求、想长期用，选 **CN2 GIA-E 季付 $49.99**，线路好、价格合理、机房可切换。这两个是大多数新手用户的起步选择。
